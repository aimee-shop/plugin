# OpenAI submission notes

The versioned ChatGPT/Codex adapter and submission checklist are generated at
`dist/openai/` (`marketplace.json`, `aimee-shop/`, `SUBMISSION.md`).

Edit `aimee-shop/` and `scripts/build-packagings.mjs`, then run
`node scripts/build-packagings.mjs`. Do not hand-edit `dist/openai/`.

This repository does not submit to the OpenAI Plugins Directory. Local/source
install is documented in the root README.
